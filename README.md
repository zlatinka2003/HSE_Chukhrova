## Что здесь

Проект содержит в себе данные о списаниях за подписку ПРАЙМ и анализирует карточные платежи за октябрь–декабрь 2025 года. Он рассчитывает долю успешных платежей, общую сумму оплат и сумму на подписку, определяет пиковые дни и показывает накопление поступлений в таблицах и графиках. Дополнительно проект сравнивает выборку из 1 000 подписок со всем сегментом, оценивает возможность обнаружить падение суммы за подписку на 5% и сопоставляет показатели разных способов оплаты за два последовательных квартала.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

## Что здесь считается

rows - выгрузка карточных платежей 1 000 подписок за октябрь–декабрь 2025 года.  

actor_id - идентификатор подписки; количество участников считается по числу его уникальных значений.

value - сумма отдельного платежа в рублях; в выручку включается только при ok = True.

ok - признак успешного платежа: True соответствует статусу success.

day - дата платежа по UTC.  

actors - количество различных подписок в рассматриваемом срезе.

events - количество всех платёжных записей, включая неудачные попытки и возвраты.

ok_events - количество успешных платежей.

ok_value - выручка: сумма известных value по успешным платежам; неудачные списания и возвраты исключаются. 

ok_share - доля успешных платежей, рассчитывается как ok_events / events.

rows_per_actor - среднее количество платёжных записей на подписку: events / actors.

value_per_ok - средняя сумма успешного платежа: ok_value / ok_events.

value_per_actor - выручка на подписку: ok_value / actors, включая в знаменателе подписки без успешных оплат.  

eligible_actors_ok - количество подписок с двумя и более успешными платежами в rows. 

date_counts - количество различных дат каждого дня недели среди всех записей rows.

weekday_means - сумма успешных платежей каждого дня недели, делённая на количество его различных дат.
